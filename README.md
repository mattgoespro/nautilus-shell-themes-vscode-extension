# Nautilus Shell Themes

A Visual Studio Code theme pack with rich, shell-language syntax highlighting. Each published theme colors the editor now and will color the rest of the workbench in a later pass.

## Themes

| Theme | Identity |
| --- | --- |
| **Nautilus Bash** | GNOME/Adwaita dark slate, accent blue, warm orange |
| **Nautilus Bash High Contrast** | Same Bash roles on a true black field |
| **Nautilus PowerShell** | Windows Terminal / VS Code Dark+ with PowerShell-specific splits |
| **Nautilus PowerShell High Contrast** | Same PowerShell roles on a true black field |

Select a theme from **File > Preferences > Theme > Color Theme**.

## Preview

Press **F5** to open an Extension Development Host with the `samples/` fixtures.
